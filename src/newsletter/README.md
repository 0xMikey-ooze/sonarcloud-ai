# Newsletter System

A weekly newsletter generator for **educators and parents**, focused on **kids audio/podcasting** and **educational AI**.

Powered by **TinyFish AI** for web search & content enrichment and **Last30Days** for curated research briefs.

---

## Features

- **React Email Templates** — Beautiful, responsive email designs with the Pedagogy Sys design system
- **Resend Integration** — Reliable email delivery with batch support
- **Primary Content Sources:**
  - **TinyFish AI** — Smart web search + page fetching for rich article summaries
  - **Last30Days** — Reads curated research briefs generated by the [last30days-skill](https://github.com/mvanhorn/last30days-skill)
- **Supplementary Sources:**
  - **Reddit** — r/podcasts, r/Parenting, r/education, r/edtech
  - **Hacker News** — Tech & education discussions
  - **GitHub** — Trending repos for kids audio, ed-tech AI, and podcasting tools
- **Content Enrichment** — TinyFish `fetchPage` extracts full article summaries from weak snippets
- **Automated Generation** — Generate and send newsletters with a single command

## Quick Start

### 1. Configure Environment Variables

Copy `.env.example` to `.env` and fill in your keys:

```bash
cp .env.example .env
```

**Required:**
- `RESEND_API_KEY` — From [resend.com](https://resend.com)
- `NEWSLETTER_FROM_EMAIL` — Verified sender domain in Resend
- `NEWSLETTER_RECIPIENTS` — Comma-separated recipient list

**Strongly Recommended:**
- `TINYFISH_API_KEY` — For web search & content enrichment via [tinyfish.ai](https://www.tinyfish.ai/)
- `LAST30DAYS_MEMORY_DIR` — Directory with last30days brief files

### 2. Generate Last30Days Research Briefs

The [last30days-skill](https://github.com/mvanhorn/last30days-skill) generates curated HTML briefs on any topic. Generate briefs for your newsletter topics:

```bash
/last30days kids podcasting --emit=html
/last30days educational AI --emit=html
/last30days children audio apps --emit=html
/last30days AI parenting tools --emit=html
/last30days classroom podcasting --emit=html
```

Move the generated `*-brief.html` files to:
- `~/Documents/Last30Days/` (default), or
- `./data/last30days/` in this project, or
- Set `LAST30DAYS_MEMORY_DIR` to your preferred location

### 3. Generate a Preview

```bash
npm run newsletter:preview
```

This aggregates content and saves an HTML preview to `output/newsletter-issue-{N}.html`.

### 4. Send the Newsletter

```bash
npm run newsletter:send
```

Or specify recipients:

```bash
npx ts-node src/newsletter/scripts/generate-newsletter.ts --send --to parent@example.com,teacher@school.edu
```

## CLI Options

```bash
npx ts-node src/newsletter/scripts/generate-newsletter.ts [options]

Options:
  --preview, -p     Save HTML preview (default if no flags)
  --send, -s        Send via Resend
  --to <emails>     Override recipient list (comma-separated)
  --no-reddit       Skip Reddit
  --no-hn           Skip Hacker News
  --no-github       Skip GitHub
  --no-tinyfish     Skip TinyFish
  --no-last30days   Skip Last30Days briefs
  --no-enrich       Skip TinyFish content enrichment
```

## Content Architecture

### Source Priority

1. **TinyFish AI** (Primary) — Searches the web for fresh articles on:
   - Kids audio & podcasting
   - Educational AI tools
   - Classroom podcasting
   - Parenting tips for screen-free learning

2. **Last30Days** (Primary) — Reads curated research briefs from local files

3. **Reddit / Hacker News / GitHub** (Supplementary) — Additional signals and community-discovered content

### Content Enrichment

When `TINYFISH_API_KEY` is set and `--no-enrich` is not passed:
- Articles with weak summaries are enriched via TinyFish `fetchPage`
- Up to 2 articles per section are deep-fetched for richer content

### Newsletter Sections

| Section | Category | Sources |
|---------|----------|---------|
| 🎧 Kids Audio & Stories | `kids-audio` | TinyFish, Last30Days, Reddit, HN, GitHub |
| 🤖 Educational AI | `educational-ai` | TinyFish, Last30Days, Reddit, HN, GitHub |
| 🎙️ Podcasting Resources | `podcasting` | TinyFish, Last30Days, Reddit, HN, GitHub |
| 👨‍👩‍👧 Parenting Tips | `parenting-tips` | TinyFish, Last30Days, Reddit |

## Troubleshooting

**No articles found?**
- Ensure `TINYFISH_API_KEY` is set for web search
- Generate Last30Days briefs and place them in the correct directory
- Check that `--no-*` flags are not disabling all sources

**TinyFish returns empty results?**
- Verify your API key at https://www.tinyfish.ai/
- Check network connectivity to `https://agent.tinyfish.ai/api/v1`

**Last30Days briefs not found?**
- Run `listAvailableBriefs()` to see detected brief files
- Ensure files are named `{topic}-brief.html`
- Check `LAST30DAYS_MEMORY_DIR` points to the right folder

**Emails not sending?**
- Verify `RESEND_API_KEY` is valid
- Ensure `NEWSLETTER_FROM_EMAIL` is a verified domain in Resend
- Check recipient emails are valid
