# Agent rules for this repo

## ⚠ The most important rule: one template, one design source

There is **exactly one email template** in this repo and **exactly one design source of truth**. Never create a duplicate. Never hand-edit HTML output files. Never hand-rebuild a "static version" of the email — every drift this project has had was caused by maintaining two templates that disagreed.

- **Design source of truth:** `design.md` (Pedagogy Sys)
- **The ONLY email template:** `src/newsletter/scripts/generate-and-send-premium.ts` (inline HTML builder, `renderPremiumHtml()`)
- **Generated output:** `output/newsletter-issue-N.html` — read-only build artifact, never edit
- **Stale/dead file:** `output/newsletter-template.html` — do not use for sends

All colors, fonts, spacing, and layout values in the template must match `design.md`. If you need a value that isn't in `design.md` yet, add it to `design.md` first, then use it in the template.

Files that are NOT allowed to exist:
- A second email template file
- Inline hex codes that deviate from `design.md`

## Newsletter sends — non-negotiable pre-flight

Before any send (`npm run newsletter:send-premium`):

1. **Mobile mode check.** Open the rendered HTML in DevTools at iPhone width. Verify the 3-cell strips stack, thumbnails shrink, no horizontal scroll.
2. **Link dogfood.** No `href="#"`, no `https://example.com`, no 404s.
3. **Subject line rules:** Under 50 chars, no emojis, no generic phrases ("Weekly Roundup"), no publication names. Use curiosity gap, benefit+number, or contrarian angle. Three options generated by curator, strongest selected.
4. **Single test recipient by default** unless the user explicitly lists more.

After sending: report the Resend message id. Note any non-200 response.

## Content pipeline

1. **Exa** (`src/newsletter/services/exa-client.ts`) — primary neural search, last 14 days, ~$0.02/issue
2. **TinyFish** — fallback if Exa returns <4 per category (currently returning 403; may be disabled)
3. **Perplexity** — fallback if both above return <4 (currently carrying most live data loads)
4. **DeepSeek curator** (`src/newsletter/services/curator.ts`) — persona-filters the raw pool, generates subject candidates
5. **Press release filter** (`content-aggregator.ts:isPressRelease`) — auto-filters PR wires, product announcements, funding announcements before curation. Checks URL domains, title patterns, and content markers.

Reddit, Hacker News, and GitHub clients were **deleted on purpose**. Don't reintroduce — they produced noisy off-topic threads.

## Persona system

Three personas rotate as the weekly "focus":
- `tech-savvy-educator` → Focus label: "Educators"
- `screen-free-parent` → Focus label: "Parents"
- `podcast-curious-creator` → Focus label: "Creators"

Every issue serves **both educators AND parents**. The primary persona only drives:
- Spotlight article selection
- Subject line angle

All articles get an audience tag: `educator` (blue), `parent` (coral), or `both` (green). Parent-facing articles show a "Try this at home" callout.

## Template features

- **600px single-column** layout, table-based for Outlook compatibility
- **Dark mode** support via `@media (prefers-color-scheme: dark)` with `.dark-bg`, `.dark-card`, `.dark-text`, `.dark-text-secondary` classes
- **Mobile responsive** via `@media (max-width: 600px)` — body text bumps to 15px, CTAs to 44px tap targets, thumbnails shrink to 72×72
- **Alt text** on all article thumbnails using article titles
- **Text-to-image ratio** ~80:20 (spam-safe)
- **HTML size** ~30KB — well under Gmail's 102KB clipping threshold
- **Sections:** Hero → Metrics (Signals, Sources, Yoto Partner Ad) → Spotlight → Field Notes → Forward CTA → Partners → Footer

## Verifying changes

When you change the template, always:
1. `npm run newsletter:send-premium` (dry-run generates preview) or run `ts-node src/newsletter/scripts/generate-and-send-premium.ts` with a test recipient
2. Open the HTML in a browser at desktop width — eyeball it
3. Resize to mobile (≤ 600px) — verify stacking, tap targets, font sizes
4. Run the link audit (`grep -nE 'href="(#"|example\.com)'` should return nothing important)
5. Check HTML size stays under 102KB
6. Only then send

## What NOT to do

- Do not edit `output/newsletter-issue-N.html` directly. It's regenerated.
- Do not introduce new color hex codes that deviate from `design.md`.
- Do not "fork" the template into a static HTML version for any reason.
- Do not commit `.env.local`.
- Do not bring back Reddit/HN/GitHub clients.
- Do not disable the press release filter without explicit user approval.
- Do not allow press releases, product announcements, or corporate PR into the newsletter — only real articles (reporting, analysis, reviews, research, opinion, practical guides).
